# 10,000步模型 clean对照评测

本实验已结束，使用50任务 clean联合微调至10,000步的模型，在 `demo_clean`＋`seen`下为每个任务计划10回合。最终458个有效策略回合、43次成功，成功率9.39%，另有42个专家阻塞槽位。原始结果见 `results/step10000-clean`。

评测采用同一模型常驻、两个隔离仿真会话的结构，FP32/eager、关闭 compile，无自动合批。小测完成后执行正式任务，实际指令、seed、动作步数与异常逐回合保存。策略正常失败进入分母，专家阻塞和异常分别统计。

该组用于历史对照，不是当前提交模型。当前提交采用20,000步模型及其 clean＋seen、randomized＋unseen结果。有效回合集合有所不同，不能仅凭汇总成功率作严格配对结论。

`driver.py`须显式选择小测或完整模式并提供开始标记；历史配置和输出用于追溯原运行。新机器或新实验应重新准备输出、来源校验和技术验证，详见 `docs/REPRODUCTION.md`。
