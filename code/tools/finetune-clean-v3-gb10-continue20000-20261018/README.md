# 第二阶段：从10,000步续训至20,000步

本阶段从10,000步完整训练状态恢复，新增10,000次优化器更新，累计达到20,000步。数据仍为相同50任务 clean V3联合训练集；没有从预训练权重重新开始，也未加入 randomized训练数据。

保留微批量1、梯度累积8、有效 batch=8，以及冻结 Qwen骨干、eager attention、梯度检查点和关闭 compile等设置。基础学习率为1e-5，按冻结配置的余弦调度运行。实际参数与恢复边界分别见 `training/step_20000/frozen-config.json`、`continuation-resume-verified.json`等记录。

每1,000步同步保存 DCP，两个阶段合计按最近两份的策略保留训练状态。20,000步训练完成后，经 CPU导出完整 HF推理模型并严格重载核验。本次提交采用该导出；公开文件不含优化器、数据游标和 RNG续训状态。

原部署配置检查使用 `launch.py --phase formal20000`，不带 `--start`时不训练。该入口限制为本次固定续训计划，不是通用的新训练启动器。新实验需独立准备配置、输出和恢复证据，避免覆盖历史记录。
