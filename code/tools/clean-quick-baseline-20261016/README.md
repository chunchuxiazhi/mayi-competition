# 原始预训练模型 clean快速基线

本实验已结束。使用指定原始预训练权重 `robbyant/lingbot-vla-v2-6b`，未微调或更新参数；场景为 `demo_clean`，指令为 `seen`，覆盖官方50个任务，每任务计划10回合。

最终形成459个有效策略回合，成功43次，有效回合成功率9.37%；另有41个专家阻塞槽位。保留1次历史中断记录，结束时无未闭合策略尝试。结果见 `results/pretrained-clean`。早期单任务 clean＋unseen探索未合并到本基线。

## 实现与结果保存

`driver.py`管理一个模型服务及最多两路仿真 worker；`serve.py`和`session_policy.py`共享一份模型，隔离各会话的 reset、动作缓存、计数、FeatureTransform和随机数状态，推理请求串行执行，不自动合批。保留单worker选项。

推理使用 FP32、eager attention、fused MoE，关闭 compile，动作 chunk长度50。场景、动作含义、官方成功判据和步数上限沿用原实现。逐回合策略与专家事件分别写入 JSONL，完成后同步落盘；正常失败计入有效回合，专家阻塞和异常另列。

任务索引为 t、回合索引为 i时，环境 seed=100000+i，策略 seed=1000000+1000×t+i，指令 seed=2000000+1000×t+i。实际指令从官方 seen候选中选择并记录。已完成的成功或失败不重复计数，显式恢复中断时保留历史尝试并使用原 seed。
