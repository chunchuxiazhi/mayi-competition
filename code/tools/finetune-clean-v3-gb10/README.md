# 第一阶段：50任务 clean联合微调至10,000步

本目录保存 GB10单机训练适配、状态保存恢复及导出工具。模型从指定原始预训练权重初始化，训练数据为50任务 clean V3数据，每任务50条演示，共2,500条、548,893帧。randomized数据不参与训练。

有效 batch为8：微批量1、梯度累积8，AdamW；启用梯度检查点，关闭 compile，使用 eager attention。冻结 Qwen骨干，视觉仍参与前向，约1.938B参数可训练。实际值以 `training/step_10000/frozen-config.json`为准。

正式训练每1,000个优化器更新步骤保存 DCP；按保留策略维护最近两份训练状态。保存采用同步流程，训练过程中不额外生成完整 HF导出，以控制统一内存峰值。HF推理权重在训练结束后经 CPU单独导出并严格重载核验。

原部署的配置检查命令为 `launch.py --phase formal10000`，不带 `--start`时不训练。训练需要外部资源及既有试训/恢复核验证据；历史输出不可覆盖。步数指优化器更新次数，不是每个任务分别更新的次数，也不是动作 chunk数。

10,000步完整续训状态已按保留策略清理，公开 HF模型仅用于推理。第二阶段的完整恢复发生在清理之前，具体边界和验证记录见 `training/step_20000`。
