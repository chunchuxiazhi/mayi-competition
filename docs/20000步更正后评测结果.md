# 20,000步模型仿真评测结果

本报告对应同一份20,000步模型在50个官方任务上的 clean＋seen 与 randomized＋unseen 评测。每个任务、每种场景计划10回合。clean记录保留原始实验，新随机场景结果来自真实 unseen 重测。

## 结果汇总

|场景|指令类型|计划回合|有效回合|成功|有效回合成功率|专家阻塞|初始化异常|
|---|---|---:|---:|---:|---:|---:|---:|
|clean|seen|500|455|65|14.29%|45|0|
|randomized|unseen|500|423|43|10.17%|76|1|
|合计|按场景区分|1,000|878|108|12.30%|121|1|

合计比例仅描述两组实际记录，不作为官方场景加权排名分数。有效回合包括策略正常失败；未形成有效回合的槽位另列，因此当前成功率只适用于已完成的有效回合集合。

## 结果保存与指令核验

clean来源为 `results/step20000-clean`，randomized＋unseen 来源为 `results/step20000-randomized-unseen`。合并文件 `results/results.json`保留100个“任务—场景”条目和每回合实际信息，来源文件的 SHA256见 `results/aggregation-manifest.json`。

unseen重测同时校正了配置约束、客户端参数和官方指令池选择。全部423个有效回合均保存 `instruction_type=unseen`、实际指令与 `instruction_evidence.pool=unseen`，并记录候选池 SHA256。缺少 unseen任务指令时明确报告异常，不改从 seen任务指令池选择。

35项 CPU回归检查通过；两个真实技术验证回合正常结束并计入计划500回合。技术验证检查会话隔离、动作格式、实际指令和持久化，不要求模型必须完成任务。这两回合均为正常策略失败，保留在结果中。

## 异常与资源

randomized有76个专家预检查阻塞槽位，另有1次记录在 `policy_exception`中的场景初始化异常：`put_bottles_dustbin`、seed100000的物体稳定性检查失败。该异常发生在模型动作推理前，不归类为模型推理崩溃。没有换 seed补选场景，没有未闭合策略尝试或中断回合。

clean运行采样最低可用统一内存约61.69GiB；unseen重测约54.61GiB。GB10的系统与GPU共享统一内存，上述数值按同一物理内存池统计。评测结束后，两路 worker和模型服务均已退出。

## 适用范围

此次随机场景成绩取代原先的 randomized＋seen 实验，未沿用其回合结果或只修改标签。历史证据保留运行时内容；若其中准备说明与当前文字不同，以冻结配置和逐回合实际记录判定实验设置。

官方允许受算力/时间限制时按实测次数提交、最终以官方复测为准。专家采集失败后仍须继续 policy测试，而现有实现对元数据的依赖仍导致部分槽位阻塞；正式 JSON字段模板也尚待登录核实。这些情况限制了当前结果的覆盖范围，已在提交说明中披露。
