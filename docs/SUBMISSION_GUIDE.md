## 只检查材料，不启动实验

在完整包的02目录执行：

```bash
bash eval.sh
bash eval.sh --hash-model
bash train.sh
```

默认入口只检查材料并打印原部署命令。`--hash-model`读取模型文件计算校验值，不做动作推理。小审阅包需增加 `--preview`，其缺少权重的状态会明确标记。

原部署训练和评测均已结束，历史目录不应覆盖启动。源码入口包含来源、资源、配置和小测检查，新机器仍需部署外部依赖并验证HF-only来源入口；当前材料不保证任意机器解压后即可从零运行。
